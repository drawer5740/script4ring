Script4Ring

Script4Ring is a small, client-side webring navigator. Add one script tag to your site, list the ring members as slug/domain pairs, and link to the next, previous, or a random member.

1. Add Script4Ring

Put this tag in your HTML. Replace the example script URL with the address where main.js is hosted. Add every member as a slug followed by a domain in data-members. 

<script
  src="https://example.com/main.js"
  id="script4link"
  data-members="SLUG123 hi.neocities.org
DrAWER drawer5740.neocities.org
LookAtMeIHaveATLD hi.com
hi hi.hihihihi.net
grok grok.neocities.org"
  defer></script>

The member list is split on whitespace, so spaces, tabs, and line breaks all work. Each pair is slug domain. Slugs may contain only English letters and numbers.

2. Add navigation links

Use your own slug in the Next and Previous links. It must match the slug assigned to your domain in data-members. 

<a href="?SLUG123-next">Next</a>
<a href="?SLUG123-previous">Previous</a>
<a href="?random">Random</a>

URL options

?random
Go to a random member.
?s4r=random
The same random action, useful alongside other query parameters.
?SLUG123-next
Go to the member after SLUG123.
?SLUG123-previous
Go to the member before SLUG123.
?s4r=SLUG123-next
Next, using the named parameter.
?s4r=SLUG123-previous
Previous, using the named parameter.

When your URL already has parameters

Use &s4r= to add Script4Ring without replacing the existing query string.

<a href="?page=home&s4r=random">Random</a>
<a href="?page=home&s4r=SLUG123-next">Next</a>

How it works

The script reads the data-members attribute from the script4link tag. It pairs each slug with the domain immediately after it. Next and Previous follow the order in the list and wrap around at either end. Random avoids the current domain when another member is available.

Self-hosting

Download main.js and upload it to your own website. For example, placing it in your site's root makes it available at https://yourdomain.com/main.js.

Then change the script URL in your installation tag to your own main.js address.
